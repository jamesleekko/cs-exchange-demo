# 熔炉光柱爆发特效实现规范

## 目标

在保留现有 Blender 炉体、机械开合动画和稀有度配色的前提下，重做揭晓阶段的实时特效。最终效果需要具备清晰的蓄能层次、可靠的浏览器性能和接近 3A 游戏演出的光照反馈。

本次不重做炉体 GLB，不导出 Blender 粒子、体积火焰或灯光。Blender 继续负责炉体、机械动画和特效锚点；Three.js 负责光柱、粒子、动态受光、Bloom 和爆发；Vue/CSS 负责覆盖全部 UI 的最终白场。

## 时间轴

时间以熔炉进入 `opening` 阶段为零点，沿用当前 `7.4s` 总时长。

| 阶段 | 时间 | 视觉要求 |
| --- | --- | --- |
| 机械开启 | `0–2.86s` | 炉体解锁、抬升和轻微震动，不提前显示主光柱 |
| 细柱显现 | `2.86–3.16s` | 白热核心由炉口向上显现，持续严格为 `0.3s`；外焰和粒子保持克制 |
| 稳定蓄能 | `3.16–5.80s` | 主光柱逐渐变亮、增宽；两圈圆形火焰粒子反向环绕；炉体受光同步增强 |
| 能量压缩 | `5.80–6.88s` | 粒子密度、转速、核心亮度和脉冲频率提升；外层略收束，形成爆发前张力 |
| 白光爆发 | `6.88–7.40s` | 核心过曝、冲击环和火星只形成一个主峰；白场在 `0.52s` 内覆盖整个视口，并轻微泛出结果品质色 |
| 结果衔接 | `7.40s+` | 在全白帧切换结果内容，再淡出白场，不出现黑帧或 UI 穿帮 |

## 渲染分层

### 光柱

- 复用 `coreColumn`、`outerColumn` 和 `auraColumn`，不增加重复柱体。
- 三层使用同一张运行时生成的周期噪声纹理和同一 Shader 结构。
- Core 是细白热核心，最先出现；Outer 是品质色主体；Aura 是低透明度外焰，延迟进入。
- Shader 使用向上显现遮罩、滚动噪声、视角软化和轻微顶点扰动，不使用体积 raymarch。
- GLB 中现有 `Energy_Beam*` 只作为低透明度装饰轮廓，避免和运行时主光柱争抢亮度。

### 粒子

- 复用单个 `THREE.Points` 和现有 `1100` 粒子池，不增加 draw call。
- 新增水平圆轨道粒子类型：内外两圈反向旋转，使用圆形 soft-particle 即可。
- 蓄能期间提高发射率和转速；爆发前粒子轻微向核心收束。
- 粒子必须淡入淡出，避免生成时闪跳；BufferAttribute 使用动态更新标记。

### 灯光与后期

- 保留 ACES 色调映射，增加 `RenderPass -> transparent bloom -> OutputPass`。
- Bloom 只在主光柱阶段运行；待机和机械开合继续直接渲染，降低常驻成本。
- 透明 Bloom 必须扩散 RGBA，不能把透明画布变成黑色全屏层。
- `mouthLight`、`columnLight`、`flashLight`、发光材质强度和 Bloom 使用同一组阶段包络。

### 整屏白场

- 白场使用 Vue 状态驱动的固定定位 DOM 层，层级高于炉体、合同和结果 UI。
- `onClimax` 开始以 `0.52s` 渐变至品质色白场；中心保持纯白，外围光晕和全屏 veil 只混入少量结果品质色，不能变成纯色蒙版。
- 白场颜色在爆发触发时锁定为当前结果的 `cfg.color`；`onDone` 先切结果，再在下一绘制帧淡出。
- `prefers-reduced-motion` 下取消扩张和震动，仅保留快速、不闪烁的透明度切换。

## 性能与降级

- 桌面 DPR 上限 `1.6`，移动端上限 `1.25`。
- Bloom 使用半浮点渲染目标；不支持 WebGL2 浮点颜色缓冲时自动绕过后期。
- 移动端降低 Bloom 强度，不增加粒子上限；低动态模式绕过 Bloom。
- 所有新增纹理、材质、Pass 和 render target 必须在 `dispose()` 中释放。

## 可观测性与验收

熔炉 canvas 使用 `data-fx-stage` 暴露 `idle / mechanical / thin / charge / surge / whiteout / done`，仅用于稳定的视觉烟测。

- `npm run build` 必须通过，且不能出现新的运行时错误。
- 桌面 `1440x900` 与移动端视口均需截图检查四个关键阶段。
- Canvas 在待机和动画阶段都必须存在非透明像素，模型加载后不能空白。
- 细柱必须与 `FX_Mouth`、喷嘴轴心对齐；圆环粒子不能漂离光柱。
- 白场必须覆盖完整 viewport，峰值帧不得漏出顶栏、舞台或边缘。
- 重置后不得残留白场、粒子、RAF、音频或后期 render target。

## 修改范围

- `src/three/furnace.js`：时间包络、光柱 Shader、轨道粒子、Bloom、质量分级和阶段标记。
- `src/three/transparent-bloom.js`：Three `0.180.0` 的透明 Bloom 适配。
- `src/App.vue`：全屏白场状态、结果切换和清理。
- `scripts/test-furnace.mjs`：关键阶段视觉烟测和错误检查。
